# 第八阶段：多轮模拟面试

## 目标

提供可独立启动、也可与岗位分析串联的受控面试练习闭环。用户可围绕本次岗位完成 1–10 轮或手动结束的循环技术问答，逐轮获得反馈、追问与最终复盘。

## 流程

```text
岗位分析结果（或独立输入）
-> 用户确认开始
-> 生成首题
-> 用户提交回答
-> 评价回答并生成追问
-> 达到最大轮数或用户结束
-> 生成复盘报告
```

## 实现

- `app/services/interview_session.py` 定义会话上下文、单轮反馈、问答记录与最终复盘；
- 固定轮数限制为 1–10；循环模式使用 `max_rounds=None`，仅用户提交回答才推进，直到用户主动结束；
- 首题、逐轮评价/追问、最终复盘分别使用独立 Prompt 并要求 JSON 输出；
- 支持混合选择三种题目来源：岗位技术理论、简历项目经历、用户上传的自选题库；
- 上下文复用本次 JD 解析、岗位匹配、完整简历、有效项目证据和预生成面试题；独立面试按所选题源显示对应资料区，只读取勾选的资料，不读取隐藏的分析页临时简历；
- 自选题库支持 PDF、docx、txt、md，按行提取并去重，仅保留在当前页面会话，不写入资料库或本地文件；
- Streamlit 使用 `st.session_state` 保存当前问题、已完成问答、反馈、轮数与总结；
- 切换页面或重新执行岗位分析不清空已有面试；主动重新开始面试时才重置当前面试。进行中的面试始终使用启动时的上下文。

## 页面交互

1. 从左侧进入“岗位分析”，完成分析后先查看结果，再点击“去模拟面试”；也可直接从左侧进入“模拟面试”，选择“独立面试”并提供资料；
2. 面试上下文选择“独立面试”或“通过岗位分析结果进行面试”。勾选题源、1–10 轮或循环模式；独立模式按题源展开历史 JD、简历库与上传区，支持多选。历史结果模式需在同页选取一份分析并确认真实简历；
3. 点击“开始模拟面试”并通过校验后生成首题。切换页面或点击“去模拟面试”本身不调用模型；
4. 阅读当前问题并提交回答；
5. 查看评分、表现亮点、优先改进点和建议回答结构；
6. 继续下一题，或在至少完成一轮后提前结束并生成复盘；
7. 查看强项、薄弱点、推荐回答结构和后续练习建议；进行中、复盘失败待重试、结束后均可通过标签查看每一轮完整记录。

每轮记录包括问题、用户原始回答（保留首尾空白）、题目来源、分数、strengths、improvements、answer_structure 和 overall_feedback。面试进行中只展示当前问题、作答区和已答轮次记录；可随时回到岗位分析页查看五步结果与工具记录，再返回继续回答。切页保留未提交草稿、当前题目和全部已答轮次，另开独立面试也不会清除已有分析。

## 边界与降级

- 进行中的会话和未保存的复盘只保存在当前页面；阶段九已加入“保存本次复盘”和历史查看，主动保存后重启可查看，但不能跨重启续答未完成面试；
- 仅空白回答会在本地被拦截；“没有相关经历”等诚实回答会交给模型如实评价，不要求用户编造经历；
- 选择“岗位技术理论”时必须提供岗位 JD；系统不会在缺少 JD 的情况下退化为泛化计算机题；
- 选择“简历项目经历”时必须取得真实完整简历：在独立面试中勾选简历库记录，或勾选自行上传/输入。多份简历按同一候选人资料合并；空正文或失效选择均拒绝启动。通过历史岗位分析面试时仍会核对原简历指纹；
- 选择自选题库时（包括混合来源）必须上传有效题库；理论题或题库独占模式不要求简历；
- 评分 Prompt 使用明确的 0–100 分档，要求纯数字等无语义输入低分、无可验证亮点；禁止根据简历经历替本轮回答补充内容或给出无依据的正向评价；
- 题目来源由代码按用户选择白名单校验；缺失或越界来源直接报错，拒绝该题，不再只改标签。仅选择理论题时不提供项目内容。题目正文的语义合规和严格评分仍依赖模型遵循 Prompt，标签校验不等于语义验证；
- 首题或逐轮输出无有效问题、来源非法、回答为空或 JSON 解析失败时，不推进问答记录，可重试；
- 最后一轮回答先保存，再生成复盘；复盘失败进入“待生成复盘”，禁止继续提交答案，用户点击“重试生成复盘”即可恢复，不重复记录或评分。提前结束失败也采用同样行为；
- 不保存 API Key，也不新增远程数据存储。

## 验收标准

- 用户可以完成至少三轮问答；
- 每轮可看到针对本次回答的反馈；
- 达到最大轮数时自动生成复盘；
- 用户可在完成一轮后提前结束；
- 轮数限制、空回答和总结生成均有自动化测试。

## 收尾验证（2026-09-08）

新增独立输入组装测试与 Streamlit AppTest 页面回归：覆盖简历缺失、RAG 全文选择、无 JD 手动选择、组合入口等待确认、完整分析保留、逐轮完整反馈、重新开始清空草稿以及复盘失败重试。移除未读取的 `last_interview_feedback`，反馈仅保存于轮次记录。

测试使用模拟模型和资料库，不访问真实用户数据；真实模型评分和出题质量仍需人工抽查。题库按行提取的限制保留：答案、备注可能被识别为题目，尚未加入语义题目清洗。

2026-09-09 交互更新：岗位分析、总结和逐轮反馈改用标签页；独立资料按题源展开，下拉勾选可再次点击取消。具体说明见 `page_layout.md`。
