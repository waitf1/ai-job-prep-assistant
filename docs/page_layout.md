# 页面布局：左侧导航四分区

更新时间：2026-09-09。采用方案一，在现有 Streamlit 应用内按任务切换页面。

## 各页面职责

- **岗位分析**：“分析资料与设置”为固定的带边框容器，不再折叠。分析结果以能力匹配、简历建议、面试准备、岗位要求、项目证据与检索详情、工具调用过程六个标签展示。点击“去模拟面试”预选本次分析，确认开始前不调用模型。
- **模拟面试**：上下文只有“独立面试”和“通过岗位分析结果进行面试”。独立面试先勾选题源，再显示对应资料区；岗位分析面试可选择当前会话结果或已保存历史分析。所有面试选择使用下拉勾选面板，再次点击即可取消。
- **资料库**：简历预览用“查看完整简历”按钮打开可关闭弹窗。管理区单独勾选要删除的简历，再点击删除并在弹窗确认；“清空简历库”同样二次确认。关闭或取消弹窗不会修改数据。
- **历史记录**：首页为摘要列表，可按类型和时间筛选。悬停摘要或键盘聚焦可查看更详细预览，右侧“查看详情”进入记录。分析与面试复盘均复用标签页组件，删除记录用二次确认弹窗。

## 独立面试资料与轮数

- “岗位技术理论”展开 JD 来源：可多选历史岗位 JD，也可选择“自行上传或输入”后上传多份文件、粘贴 JD。历史 JD 来自已保存岗位分析，不另建或迁移 JD 数据库。
- “简历项目经历”展开简历来源：可多选完整简历库记录，也可自行上传或输入完整简历。多份简历视为同一候选人的资料合并；不会使用未勾选的简历或隐藏的旧输入。
- “自选题库”展开多文件上传，题目去重后只保留在当前会话。
- 多份 JD 合并为考察范围，不分别创建面试。取消题源或资料来源后，其隐藏内容不再进入本次上下文。
- 轮数支持 1–10，默认 3；也可选择“循环直到自行停止”。循环模式只在用户提交回答后调用模型，不自动连续出题。至少完成一轮后可结束并生成复盘，失败可以重试；空场可重新开始。
- 历史分析面试在点击开始时重新读取记录并核对原简历指纹；无法恢复原简历时需选择替换简历并确认，内容变化会清除旧项目匹配及证据。

侧栏仅保留四项导航、当前分析/面试状态及简短使用说明。

## 状态与调用边界

- 导航不会执行岗位工作流、生成面试问题或清空当前会话。
- 简历、JD、补充说明、分析模式和手动选择的简历跨页保留。输入区的修改不改写已生成结果的原始岗位及历史快照。
- 面试来源、轮数、已解析题库、当前题目、回答草稿、已完成轮次均跨页保留。新的分析不会替换进行中面试的上下文。
- 历史筛选、选中记录、替换简历输入和确认状态在当前会话中保留。
- Streamlit 会清除未展示控件的值。`app/ui/session_widgets.py` 显式保留可编辑字段；上传控件自身不保留，已解析的文字与待入库文档独立暂存并显示文件名。“清除本次上传”会清除这份暂存，成功入库后也会清除该批暂存。
- 岗位分析上传解析失败时保留草稿并拦截提交，移除失败文件或编辑文本后可继续。独立面试的批量上传解析失败时需重新上传有效文件或点击“清除本次上传”，不会静默使用旧文件。
- 普通页面不初始化项目向量库；进入项目资料管理或真正执行 RAG 分析时才读取它。
- 跨页保留属于当前浏览器会话能力。刷新或重启后，只有主动保存的简历、项目资料、分析和复盘可恢复；未完成面试不能跨重启续答。

## 代码与验证

- `app/main.py`：导航、共享输入、分析与面试控制。
- `app/ui/analysis_result.py`：当前及历史分析结果展示。
- `app/ui/library_page.py`：简历与项目资料管理。
- `app/ui/history_panel.py`：历史筛选、恢复和删除。
- `app/ui/session_widgets.py`：跨页状态与上传暂存。
- `app/ui/choices.py`：可取消勾选的下拉面板。
- `app/ui/interview_setup_panel.py`：按题源显示资料、历史分析选择及上下文组装。
- `tests/test_page_navigation.py`、`tests/test_interview_ui.py`、`tests/test_history_ui.py`：页面隔离、状态保留与流程回归；测试使用模拟模型和资料库。
- `tests/test_upload_ui.py`：失败上传拦截、手动编辑/移除文件后恢复、简历删除确认隔离。

2026-09-09 完整测试结果：134 项通过。新增 `test_interview_design.py` 覆盖轮数、循环模式、资料勾选、历史 JD 合并及简历弹窗。浏览器使用隔离的演示资料验证标签切换、取消题源、简历弹窗右上角关闭及历史摘要浮层；没有调用真实模型或删除用户资料。

运行完整测试：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py" -v
```

